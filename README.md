# hxyfront-62013 木结构榫卯构件测绘归档台

源提示词编号：8

## 功能

针对"照片编号记在纸单上、现场对不上构件"的问题，将样例页补成测绘归档台：

- **构件记录**：建筑、编号、木材、榫型、截面、病害位置（另带选填病害说明）。
- **病害登记**：近景与整体照片编号缺一不可，缺一项即停在**待补拍**；同一编号只能归一个病害（重复编号保存被拒）。病害位置填"无病害"时免登照片。
- **待补拍筛选**：构件清单、尺寸记录表、病害标记图共用建筑 / 榫型 / "待补拍·复核中"筛选；指标卡可一键看待补拍。
- **关系视图**：按单栋建筑展示，只收录**已归档**构件，未归档构件列在旁边但不入图。
- **修正与复核**：截面、病害位置（及照片编号等核对字段）修正后照片沿用、记录不丢；归档快照与现状不一致时自动转入**复核中**，重新核对通过后再归档。

## 分层（归档判断 / 保存 / 页面操作分开）

- `src/domain/types.ts`：记录、表单、状态类型。
- `src/domain/archive.ts`：**归档判断纯函数**——缺项核对、状态推导、归档快照、编号去重、构件归类，不碰存储与界面。
- `src/data/repository.ts`：**保存层**——localStorage 读写、演示数据；读取时用归档判断重新校准状态。
- `src/hooks/useMembers.ts`：**页面操作层**——保存、归档、删除、重置的动作编排。
- `src/components/`：录入表单、筛选条、清单、尺寸表、标记图、关系视图。
